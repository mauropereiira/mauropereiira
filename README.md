I'm a Happiness Engineer at [Automattic](https://automattic.com), working on WordPress.com from Portugal. Support is a front-row seat to software failing people, so the things I build lean hard the other way: local-first, plain Markdown, no accounts, everything on your own disk.

If any of my apps disappeared tomorrow, your data would still be a folder of files that opens in anything. That's the whole design philosophy.
